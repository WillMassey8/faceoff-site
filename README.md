# Face Off site

Public marketing, privacy, support and photo-credits pages for Face Off: 1v1 Sports Trivia.

Intended to be served by GitHub Pages from the `main` branch root at `https://willmassey8.github.io/faceoff-site/`.

## Support email

The support address is the literal string `support email coming soon` until Will chooses one. Replace that exact string in:

- `js/config.js` (`SUPPORT_EMAIL`)
- `privacy/index.html` and `support/index.html` (and `credits/index.html`) where the same text appears as a no-JS fallback
